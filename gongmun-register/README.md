# 📋 공문 관리 대장 (Google Apps Script)

구글 시트에서 쓰는 공문 관리 대장입니다. 문서번호(`GC` + `YYMM` + 월별 순번)와 작성일자가 자동으로 기재됩니다.

## 파일

| 파일 | 역할 |
|---|---|
| `Code.gs` | 대장 서식, 자동 채번, 드롭다운, 메뉴 |
| `Sidebar.html` | [새 공문 등록] 입력 창(사이드바) |
| `appsscript.json` | 프로젝트 설정 (서울 시간대, V8) |

## 설치 (약 3분)

1. 새 구글 시트를 만듭니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 `Code.gs` 내용을 지우고 이 폴더의 `Code.gs`를 붙여 넣습니다.
4. 왼쪽 **파일 ＋ → HTML**을 눌러 이름을 `Sidebar`로 만들고 `Sidebar.html`의 내용을 붙여 넣습니다.
5. (선택) **프로젝트 설정 → "appsscript.json" 매니페스트 파일 표시**를 켜고 `appsscript.json`을 붙여 넣습니다.
6. 저장한 뒤 함수 목록에서 `setupRegister`를 골라 **실행**하고, 권한 요청을 승인합니다.
7. 시트로 돌아가 새로고침하면 상단에 **📋 공문 관리** 메뉴가 생깁니다.

## 사용법

- **📋 공문 관리 → ✏️ 새 공문 등록** (권장): 부서·작성자를 칩으로 고르거나 직접 입력하고, 수신처와 제목을 쓴 뒤 등록하면 번호가 자동으로 붙습니다.
- **표에 바로 입력**: 빈 행에 작성부서, 작성자, 수신처, 제목 가운데 하나라도 입력하면 문서번호와 작성일자가 자동으로 기재됩니다.
- **드롭다운 목록 수정**: **📋 공문 관리 → 🧾 드롭다운 목록 편집**(`설정` 시트)에서 부서나 작성자를 추가하거나 지우면 바로 반영됩니다.

## 문서번호 규칙

```
GC  +  YYMM  +  순번(01~)
고정    연·월    매월 01부터 다시 시작
```

예) 2026년 10월 1번째 → `GC261001`, 2번째 → `GC261002`, 11월 1번째 → `GC261101`

- 순번은 해당 월에 쓰인 가장 큰 번호에 1을 더해 매깁니다. 동시에 입력해도 번호가 겹치지 않도록 잠금 처리되어 있습니다.
- 취소된 공문은 행을 지우지 말고 비고에 `취소`라고 적어 주세요. 그 달의 마지막 행을 지우면 그 번호가 다시 쓰일 수 있습니다.
- 문서번호와 작성일자 열은 수정할 때 경고가 뜨도록 보호되어 있습니다.
