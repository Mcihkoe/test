# 쇼츠 #01 — 잠들 때 몸이 '툭' 떨어지는 이유

| 항목 | 내용 |
|---|---|
| 업로드 제목 | 잠들 때 몸이 '툭' 떨어지는 이유 |
| 화면 상단 제목 | 잠들 때 몸이 '툭' / **떨어지는 진짜 이유** (2줄, 흰색 + 빨간색) |
| 길이 | 41.8초 · 1080×1920 · 30fps |
| 주제 선정 이유 | 거의 모든 사람이 겪어본 현상이라 공감형 댓글("나도 그럼")이 잘 달리고, "~하는 이유"는 벤치마크 3개 채널이 공통으로 쓰는 제목 공식 |

## 파일
- `short.mp4` — 완성본 (내레이션 + BGM + 효과음 + 자막)
- `short_no-narration.mp4` — 내레이션만 뺀 버전 (BGM + 효과음 + 자막). 더 자연스러운 AI 보이스로 더빙할 때 사용
- `subtitles.srt` — 자막 타이밍 (보이스 녹음 시 가이드)
- `thumbnail.jpg` — 커버 프레임
- `src/` — 대본(`script.py`)과 렌더링 스크립트(`build.py`). 대본만 바꾸면 같은 스타일로 새 쇼츠를 만들 수 있음

## 대본 (내레이션)
| # | 장면 | 내레이션 |
|---|---|---|
| 1 | 밤, 침대에서 자는 사람 → '툭!' 화면 흔들림 | 잠들기 직전, 몸이 갑자기 **툭!** 하고 떨어지는 느낌. 한 번쯤 겪어보셨죠? |
| 2 | '입면 경련' 카드 + 10명 중 7명 표시 | 이걸 '입면 경련'이라고 하는데, 무려 10명 중 7명이 겪는다고 함. |
| 3 | 뇌 + 물음표 → '착각' 도장 | 원인은 바로, 뇌의 착각. |
| 4 | 근육 긴장도 게이지 하락 | 잠이 들면서 온몸의 근육이 한순간에 풀리는데, |
| 5 | 빨간 경보 + "추락 중!!!" | 뇌가 이걸 '지금 추락 중'이라고 오해해버림. |
| 6 | 번개 신호 → 몸이 '움찔!' | 그래서 몸을 지키려고, 근육에 긴급 신호를 보내 **움찔!** 하게 만드는 것. |
| 7 | 나무 위 원숭이 → 추락, X 표시 | 나무 위에서 자던 원숭이 조상 시절의 흔적이라는 가설도 있음. 그땐 자다 떨어지면, 끝이었으니까. |
| 8 | 커피 / 스트레스 / 피로 카드 | 특히 커피, 스트레스, 피로가 쌓인 날 더 자주 나타남. |
| 9 | 뇌 + 방패 + 하트 | 그러니까 오늘 밤 **툭!** 했다면, 당신 뇌가 당신을 구하려던 겁니다. |

## 업로드용 설명 / 해시태그
```
잠들기 직전 몸이 '툭' 떨어지는 느낌, 겪어본 사람? 🙋
#입면경련 #수면 #잠 #뇌과학 #신기한사실 #쇼츠 #shorts
```

## 사실 확인 메모
- 입면 경련(hypnic jerk)은 인구의 약 60~70%가 경험한다고 알려짐 → "10명 중 7명"
- 근육 이완을 뇌가 추락으로 오인한다는 설명, 영장류 조상 흔적설은 **가설**이므로 대본에서도 "가설도 있음"으로 표현함
- 카페인, 스트레스, 피로, 수면 부족이 빈도를 높이는 요인으로 알려짐. 대부분 무해함

## 제작 환경의 한계
- 내레이션은 오프라인 TTS(espeak-ng)라 기계음이 강함 → 업로드 전에 `short_no-narration.mp4` 위에 CapCut, 타입캐스트, ElevenLabs 등 자연스러운 보이스로 더빙하는 것을 권장 (`subtitles.srt` 타이밍 참고)
- 벤치마크 채널처럼 3D 캐릭터·실사 영상을 쓰려면 AI 영상 생성 크레딧이 필요함 (현재 Higgsfield 크레딧 0)
