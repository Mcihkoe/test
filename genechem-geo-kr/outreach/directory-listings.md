# 원료 디렉토리 등재용 문구 초안

이 문서는 실제 검색 테스트("AQP3 활성화 화장품 원료 공급 회사")에서 진켐 대신 노출된
디렉토리/리스트형 사이트에 등재를 신청할 때 붙여넣을 수 있는 문구 초안입니다.

**대상 사이트** (2026-09 검색 결과 기준 상위 노출 확인):
- 대한화장품협회(KCIA) 성분사전 — https://kcia.or.kr/cid/search/com_list.php
- ezcos.co.kr 원료업체 리스트
- chemknock.co.kr
- 하나케어(화장품 원료 전문기업 리스트/커뮤니티)

> ⚠️ 유의: 위 사이트들은 사이트마다 등재 방식이 다릅니다. 일부(KCIA 성분사전 등)는
> 화장품 원료 성분 정보 등록에 사업자 확인, INCI 등록 여부 등 공식 절차/서류가 필요할 수
> 있습니다. 아래 문구는 "제출용 텍스트"이며, 각 사이트의 실제 등록 양식·요건은 별도로
> 확인이 필요합니다. 담당자 연락처 등 진켐 내부 정보만 빈칸으로 남겨두었습니다.

---

## 1. 회사소개 (등재용, 두 가지 길이)

### 짧은 버전 (~100자, 리스트/테이블형 등재용)
> (주)진켐(GeneChem)은 효소공학·글리코실레이션 기술 기반으로 화장품 기능성 원료를
> 자체 개발·생산하는 특허 보유 바이오 소재 기업입니다.

### 긴 버전 (~300자, 회사 프로필 등재용)
> (주)진켐(GeneChem Inc.)은 효소 공정 기반 효소공학(Enzyme Engineering) 및
> 글리코실레이션(Glycosylation) 기술을 보유한 바이오 소재 기업입니다. 자체 효소
> 공정을 통해 화장품 기능성 원료를 생산하며, 대표 원료로 아쿠아포린-3(AQP3)
> 활성화 기반 보습 원료 'AquaGG'를 보유하고 있습니다. 특허 보유 기업으로,
> 화장품 제조사/브랜드를 대상으로 원료를 B2B로 공급합니다.

## 2. AquaGG 원료 소개 (성분/제품 등재용)

| 항목 | 내용 |
|---|---|
| 원료명 | AquaGG |
| INCI명 | 2-α-글리세릴글루코사이드(2-α-Glyceryl Glucoside) |
| 분류 | 화장품 기능성 원료 (보습) |
| 작용 기전 | 아쿠아포린-3(AQP3, 피부 세포의 핵심 수분 채널 단백질)를 특이적으로 활성화 |
| 주요 효과 | 깊고 지속적인 보습, 피부 장벽 강화, 탄력 개선(콜라겐/엘라스틴 생성 지원) |
| 순도 | 90% 이상 |
| 용해성 | 수용성 |
| 배합 안정성 | pH 3~9 |
| 유래 | 극한 가뭄에도 수분을 유지하는 '부활초(Resurrection Plant)'의 생존 원리에서 착안 |
| 공급 범위 | 국내 화장품 제조사/브랜드 (B2B) |
| 생산 방식 | 자체 효소 공정 |

### 등재용 한 문단 소개
> AquaGG(2-α-글리세릴글루코사이드)는 진켐이 자체 효소 공정으로 생산하는 화장품
> 기능성 원료로, 피부 세포의 수분 채널인 아쿠아포린-3(AQP3)를 특이적으로
> 활성화하여 깊고 지속적인 보습, 피부 장벽 강화, 탄력 개선 효과를 제공합니다.
> 순도 90% 이상의 고순도 원료이며 pH 3~9 범위에서 안정적으로 배합할 수
> 있습니다. 극한 건조 환경에서도 수분을 지켜내는 '부활초'의 생존 원리에서
> 착안해 개발되었습니다.

## 4. 등재 후 확인할 것

- 등재된 페이지가 실제로 구글에 색인되는지 `site:` 검색으로 확인
- 등재 페이지에 진켐 공식 사이트로의 링크(백링크)가 걸리는지 확인 — 없다면 요청
- 등재 후 2~4주 뒤 "AQP3 활성화 화장품 원료 공급 회사" 등 기존에 테스트했던 브랜드명
  미포함 쿼리로 재검색해 순위 변화 확인
